# Your First AI-Assisted Action in Dynamics 365

In this exercise, you'll use Copilot in VS Code to prepare **one purchase order** in a Dynamics 365 practice environment. You don't need coding or Dynamics 365 experience. Follow the files in order; ask your facilitator if your screen or the instructions don't match.

**Start here**

1. [Set up VS Code and check the connection](exercise-guides/setup-guide.md).
2. Read the [scenario card](exercise-guides/scenario-card.md). It contains the request and the details you'll need.
3. Follow the [exercise guide](exercise-guides/exercise-guide.md). Fill in the prompt yourself, check Copilot's preview, and confirm only when every detail is correct.
4. You're done. Leave the purchase order as it is. The [MCP example](exercise-guides/mcp-in-dynamics-example.md) is optional; the [glossary](exercise-guides/glossary.md) explains unfamiliar terms.

**What's in the folders**

- `exercise-guides/` contains the learner instructions, scenario, glossary, and optional reading.
- `.github/copilot-instructions.md` contains instructions Copilot follows in this workspace. You don't need to edit it.
- `.vscode/` contains the example Dynamics 365 connection settings. You don't need to edit them.
- Custom agents and skills are not included. If added later, their usual locations are `.github/agents/` and `.github/skills/`.

**Agents, skills, and tools**

For this exercise, use Copilot Chat in **Agent mode** and the **d365-erp** tools. Agent mode lets Copilot use connected tools to read or create Dynamics 365 records. A custom **agent** is a specialist Copilot setup; a **skill** is reusable instructions for a task. You don't need to install or select either to complete this exercise.

**Time:** about 30–45 minutes, including setup. The environment is for practice and is separate from real business data.
